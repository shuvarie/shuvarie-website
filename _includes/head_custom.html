{%- comment -%} Auto color scheme: just-the-docs' `color_scheme` setting only supports "light" and "dark" — there is no "auto". The theme's head already links the light stylesheet (just-the-docs-default.css, built from `color_scheme: light`); here we additionally link the theme's self-contained dark stylesheet so it applies only when the visitor's system prefers dark. It loads after the default stylesheet, so the last matching sheet wins. {%- endcomment -%}
